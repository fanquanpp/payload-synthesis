# 载荷合成 · PAYLOAD SYNTHESIS
一款用 Three.js 写的合成消除游戏（合成大西瓜玩法），美术与 UI/UX 全部采用
**NASA 朋克（NASA-punk）**风格 —— 70 年代航天规范手册的功能美学：米白烤漆硬件、
面板接缝与铆钉、黑白警示斜纹、全大写小编号、单一红色强调色、诚实的磨损痕迹。

横屏与竖屏共用同一套物理与玩法，外围布局自适应切换。

**[ 在线试玩](https://fanquanpp.github.io/payload-synthesis/)**

---

## 运行
```bash
cd payload-synthesis
python -m http.server 8123
# 打开 http://127.0.0.1:8123/
```

Windows 下双击 `start.bat` 亦可。部署在 GitHub Pages 上时同样是零配置静态站点。

## 玩法
| 操作 | 说明 |
|---|---|
| `←` `→` / `A` `D` | 移动投放位置 |
| `空格` / `Enter` | 投放部件 |
| 鼠标移动 + 点击 | 瞄准并投放 |
| 触摸拖动 + 抬起 | 移动端投放 |
| `Q` / 点击 HUD「剔除」 | 进入剔除模式，再点任意部件将其移除 |
| `Esc` / `P` | 暂停 / 继续（Esc 兼作退出剔除模式） |
| HUD 右上「EN / 中文」 | 中英切换（自动记住选择，首访按浏览器语言判定） |

- 两个**同级**部件接触即合并为更高一级的部件。
- 部件越过舱内红色限位线并持续 **6 秒**，任务中止。
- 连续合成累积**连锁**，得分乘以连锁倍率（上限 ×32；连锁窗口随连击数微伸长，停手即断）。
- 每累计 **10,000 分**获得一次「剔除」充能（最多存 9 次），可移除任意部件救场。
- 投放有 **0.28s 输入缓冲**：冷却期内的按键会在冷却结束的瞬间生效。

### 11 级部件阶梯
| 级 | 编号 | 名称 | 形状 | 碰撞体 |
|---|---|---|---|---|
| 1 | P/L 01 | 螺栓 BOLT | 六棱柱 | 3 圆 · 横向链 |
| 2 | STOW 84S | 传感器 SENSOR | 胶囊 | 3 圆 · 纵向链 |
| 3 | REF 12-4 | 电池组 BATTERY | 立方 | 4 圆 · 2×2 |
| 4 | GYR-A | 陀螺仪 GYRO | 球 | 1 圆 |
| 5 | TANK 5 | 储罐 CANISTER | 圆柱 | 4 圆 · 2×2 |
| 6 | NO STEP | 推进器 THRUSTER | 喷管 | 2 圆 · 底部双叶 |
| 7 | ANT 7 | 天线 ANTENNA | 环面 | 4 圆 · 环上均布 |
| 8 | F/T 08 | 燃料舱 FUEL TANK | 十二面体 | 1 圆 · 近球 |
| 9 | SM-09 | 服务舱 SERVICE MODULE | 细圆柱 | 3 圆 · 纵向链 |
| 10 | CM-10 | 指令舱 COMMAND MODULE | 锥 | 2 圆 · 底部双叶 |
| 11 | LV-11 | 运载火箭 LAUNCH VEHICLE | 大胶囊 | 3 圆 · 纵向链 |

碰撞体是**逐形状拟合**的多圆凸壳，与渲染网格同一单位：圆的并集在横向等于该件的
真实半宽、纵向等于真实半高，四角允许微量咬合。因此大件不会因"外接球"而互相悬空，
宽扁件也不会凭空浮在地面之上。圆半径再统一收 1.5%，让相邻大件轻微贴实而不是留缝。

## 美术管线
`tools/` 下两个脚本构成完整素材流程，可重跑：

```bash
python tools/fetch_textures.py     # 下载 11 张 ambientCG 1K 材质（CC0）
python tools/build_textures.py     # 加工成品贴图 → assets/tex/final/
```

加工步骤：

1. 米白烤漆底材，逐级微调色调；
2. 叠加该级**独有的功能纹样** —— 六角螺栓阵 / 格栅 / 电池组 / 同心环 /
   箍带 / 喷管 / 辐射肋 / 面板网格 / 检修口 / 隔热瓦 / 机身涂装；
3. 叠一层下载来的真实材质照片做**磨损与污渍底噪**；
4. 每级只用**一种鲜艳强调色**（红 `#D63A2C`、赭 `#D2A85E`、橄榄 `#7A7F4E`、
   板岩 `#4C5A68`、锈 `#A8432F`、蓝 `#2B4A7A`、橙 `#C8792B`、青 `#2F6E75`）；
5. 写入真实可读的**全大写钢印编号**（`STOW 84S`、`THIS SIDE UP`、`NO STEP`…）；
6. 划痕 + 轻噪点，输出 1024×512 等距柱状投影贴图。

风格刻意**不做霓虹发光**：自发光贴图接近全黑，辉光后处理强度仅 0.62 且随危险度上升。

## 视觉与动效要点
- **单一界面**：米白手册式页面 + 内嵌一块深色检查舱视窗，两种材质同属一套语言。
- **线稿感**：每个部件用反壳描边（inverted hull）勾墨线，读起来像手册插图。
  小于 5 单位半径的部件跳过描边，省下约四成绘制调用。
- **动效词汇**：机械双闸门转场、面板装配滑入、四角铆钉依次锁定、
  彩条分段充能、状态 LED 闪烁、剔除瞄准框旋转脉冲。

### 自适应布局
- **板宽自适应**：`BH` 固定，`BW` 由视口实际可用空间推导（竖屏下限 0.733 比例，
  横屏上限 1.15）。所以宽屏得到的是**更宽的舱体**，而不是被信箱化的窄柱。
- 布局用「测量真实可用区 → 反推板宽 → 把两侧栏贴到舱体旁」的方式，
  而不是让栏位漂到窗口边缘。
- 宽屏为「左状态栏 / 舱体 / 右图鉴」三栏；竖屏收起左栏，图鉴压成底部横条。
- `@container` 查询让窄舱自动收起会碰撞的角标与告警文案。

### 自适应画质
主循环监控帧率：连续 3 次低于 46 FPS 就降一档（全特效 → 降 DPR + 半分辨率辉光 →
关辉光 + 1× DPR），连续 12 次高于 57 FPS 再升回来。档位变化会写入活动日志。

## 物理求解器
- 均匀网格宽相 + 逐形状多圆凸壳窄相；每对只在其**首个共有网格**里解算一次。
- 位置求解**按半径从大到小**处理，大件先解算，小件不会被从堆里挤出去。
- 深度穿透松弛：重叠明显超出容差时额外多轮**欠松弛**推开，不会把接触推散，必要时唤醒睡眠体。
- 低速蠕变阻尼：速度低于 6 u/s 时额外阻尼，堆叠会真正停住并入睡，
  而不是以几 u/s 缓慢滑移（摩擦不足的堆会永远滑下去）。
- **穿透感知休眠**：只有当前没有与任何物体重叠时才允许入睡，避免卡在半重叠状态。
- 质量差过大时提高位置修正系数，轻件不会沉进重件里。

## 调试
- `?noraf=1` —— 用 `setTimeout` 驱动主循环替代 `requestAnimationFrame`，
  用于无头截图 / 内嵌场景（rAF 被节流时）。
  注意：该模式下帧率上限受计时器调度限制，读数偏低属正常，不代表真实性能。
- `SA.game.setAutoPause(false)` —— 关闭「页面隐藏即暂停」。
- `SA.setLang('en' | 'zh')` —— 切换语言。
- `SA.world.setQuality(0 | 1 | 2)` —— 手动指定画质档。
- `SA.game` / `SA.world` / `SA.fx` / `SA.ui` / `SA.cfg` 均挂在全局，便于控制台调试。
